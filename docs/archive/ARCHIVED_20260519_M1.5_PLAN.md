## 三、架构风险

1. **SSE 双连接**: 主聊天 SSE 连接在 hitl_request 事件后可能已关闭，resume SSE 是新连接，前端需将 resume 流的消息追加到同一会话
2. **Checkpoint 恢复**: `compiledGraph.stateOf(config)` 返回 Optional，若 state 为空则 resume 失败 fallback 到全新执行
3. **Token 超时**: 5min TTL 内用户未确认，Caffeine 自动驱逐，前端需处理 410 Gone
